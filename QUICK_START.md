# 🚀 PC Health Guardian — Краткий старт

## Что вы получили

Полноценная программа для защиты вашего ПК (Intel Celeron N4120, 8GB RAM) от перегрузок и зависаний.

## 📦 Файлы для установки на Windows

| Файл | Назначение |
|------|------------|
| `pc_health_guardian.py` | Основной модуль программы |
| `requirements.txt` | Список зависимостей |
| `install.bat` | **Автоматический установщик** (запустить от имени администратора) |
| `run_guardian.vbs` | Запуск без консольного окна (только GUI и трей) |
| `README_RU.md` | Полная документация |

## ⚡ Установка за 1 минуту

### Способ 1: Автоматически (Рекомендуется)

1. Скопируйте все файлы в папку на вашем ПК (например, `C:\Programs\PCHealthGuardian`)
2. Нажмите правой кнопкой на **`install.bat`** → "Запуск от имени администратора"
3. Дождитесь завершения установки
4. Программа запустится автоматически и появится в трее (возле часов)

### Способ 2: Вручную

```cmd
# Откройте командную строку в папке с программой
pip install -r requirements.txt
pythonw.exe pc_health_guardian.py
```

## 🖥️ Как пользоваться

### После запуска вы увидите:

1. **Окно программы** (600x500 пикселей):
   - Загрузка CPU в реальном времени
   - Прогресс-бар нагрузки
   - Вкладки: "Журнал действий" и "Правила"

2. **Значок в трее** (зеленый квадрат с "PC"):
   - Правый клик → меню управления
   - "Открыть кабинет" → показать окно
   - "Выход" → завершить программу

### Что делает программа:

✅ **Мониторит** нагрузку CPU каждые 2 секунды  
✅ **Предупреждает** при нагрузке выше 95%  
✅ **Запрашивает подтверждение** перед завершением процесса  
✅ **Запоминает** ваши решения (обучение после 3 случаев)  
✅ **Защищает** системные процессы Windows  
✅ **Проверяет** на вирусы (miner, trojan, ransom, keylogger)  

### Пример работы:

```
[14:30:15] Высокая нагрузка CPU: 97.2%
[14:30:16] Диалог: "Процесс chrome.exe нагружает CPU на 45%. Убить?"
       → Вы нажимаете "Да"
[14:30:17] KILL (Manual): chrome.exe - PID: 12345

[Через 3 подобных случая]
[14:45:00] Диалог обучения: "Создать правило всегда убивать chrome.exe?"
       → Вы нажимаете "Да"

```

## ⚙️ Настройки

### Отключить антивирус (для разработчиков):

1. Откройте программу
2. Нажмите "⚙ Настройки"
3. Снимите галочку "Включить Антивирус"

### Добавить своё правило:

1. Вкладка "🛡 Правила и Обучение"
2. Кнопка "Добавить правило"
3. Имя процесса: `тяжелая_программа.exe`
4. Действие: `kill` (убивать) или `ignore` (игнорировать)

## 🔧 Если что-то пошло не так

### Значок не появился в трее?
- Нажмите на стрелку ^ возле часов — возможно значок скрыт
- Проверьте, установлены ли зависимости: `pip install -r requirements.txt`

### Программа не запускается?
- Установлен ли Python 3.8+? Проверьте: `python --version`
- Запустите с консолью для отладки: `python pc_health_guardian.py`

### Как удалить?
1. Выйдите через значок в трее (правый клик → Выход)
2. Удалите ярлык из автозагрузки:  
   `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`
3. Удалите папку с программой
4. Удалите данные: `%USERPROFILE%\PCHealthGuardian`
