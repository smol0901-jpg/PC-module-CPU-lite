# 🛡️ PC Health Guardian v2.0

**Легковесный модуль автономной защиты и оптимизации ПК для слабых систем**

Специально разработан для: **Intel Celeron N4120, 8GB RAM, Intel UHD Graphics 600**

---

## 📋 Описание

**PC Health Guardian** — это компактная программа, которая работает в фоновом режиме (в трее) и защищает ваш компьютер от перегрузок, зависаний и потенциальных угроз. Программа автоматически отслеживает тяжелые процессы, обучается на действиях пользователя и предотвращает критическую нагрузку на процессор.

### ✨ Ключевые возможности

| Функция | Описание |
|---------|----------|
| 🎯 **Интеллектуальный мониторинг** | Отслеживание процессов в реальном времени с интервалом 2 секунды |
| 🔥 **Защита от перегрузки** | Не допускает нагрузки CPU выше 98% |
| 🦠 **Встроенный антивирус** | Обнаружение подозрительных процессов по сигнатурам (miner, trojan, ransom, keylogger) |
| 🧠 **Самообучение** | Запоминает ваши решения после 3 случаев и предлагает авто-правила |
| ⚙️ **Гибкие правила** | Создание, изменение и удаление правил для конкретных процессов |
| 💼 **Кабинет управления** | Полноценный GUI интерфейс с вкладками и статистикой |
| 🔔 **Значок в трее** | Работа в фоновом режиме до перезагрузки ПК |
| 📊 **Журнал действий** | История всех выполненных операций (до 1000 записей) |
| ✅ **Подтверждение действий** | Всегда спрашивает разрешение перед вмешательством |

## 🚀 Быстрый старт

### Вариант 1: Автоматическая установка (Рекомендуется)

1. Скачайте все файлы проекта в одну папку
2. Запустите **`install.bat`** (от имени администратора)
3. Следуйте инструкциям установщика
4. Программа автоматически добавится в автозагрузку

### Вариант 2: Ручная установка

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Запустите программу (с окном)
python pc_health_guardian.py

# ИЛИ запустите в фоне (без консольного окна)
pythonw.exe pc_health_guardian.py

# ИЛИ через VBS-скрипт
cscript //nologo run_guardian.vbs
```

## 🖥️ Интерфейс программы

### Главное окно

При запуске открывается компактное окно (600x500 пикселей) с тремя основными секциями:

1. **Верхняя панель**
   - Название программы и версия
   - Кнопка "⚙ Настройки"

2. **Статус системы**
   - Текущая загрузка CPU в процентах
   - Визуальный прогресс-бар
   - Индикатор статуса (зеленый/оранжевый/красный)

3. **Вкладки**
   - 📜 **Журнал действий** — история всех событий
   - 🛡 **Правила и Обучение** — управление правилами

### Системный трей

После сворачивания или закрытия окна программа продолжает работу в трее:

- **Значок**: Зеленый квадрат с надписью "PC"
- **Контекстное меню**:
  - "Открыть кабинет" — показать главное окно
  - "Пауза мониторинга" — временно остановить проверку
  - "Выход" — полностью завершить работу

## ⚙️ Настройки

### Антивирус

По умолчанию **включен**. Для разработчиков можно отключить:

1. Нажмите "⚙ Настройки"
2. Снимите галочку "Включить Антивирус"
3. Сохраните изменения

**Подозрительные сигнатуры:**
- miner — майнеры криптовалют
- trojan — троянские программы
- ransom — программы-вымогатели
- keylog — кейлоггеры
- cryptolocker — шифровальщики
- botnet — ботнеты

### Пороги срабатывания

Настроены оптимально для слабых ПК:

| Параметр | Значение |
|----------|----------|
| Предупреждение | 95% CPU |
| Критическая нагрузка | 98% CPU |
| Интервал проверки | 2 секунды |

## 🛡️ Система правил

### Типы правил

| Действие | Описание |
|----------|----------|
| `kill` | Автоматически завершать процесс при высокой нагрузке |
| `ignore` | Никогда не вмешиваться в работу процесса |

### Добавление правила

1. Перейдите во вкладку "🛡 Правила и Обучение"
2. Нажмите "Добавить правило"
3. Введите имя процесса (например, `chrome.exe`)
4. Выберите действие
5. Нажмите "Сохранить"

### Удаление правила

1. Выделите правило в списке
2. Нажмите "Удалить"

## 🧠 Система обучения

Программа обучается на ваших действиях:

1. При первой встрече с тяжелым процессом программа **спрашивает подтверждение**
2. После **3 случаев** с одним процессом программа предлагает создать авто-правило
3. Если вы согласны — правило сохраняется и применяется автоматически

### Пример обучения

```
[12:30:45] Высокая нагрузка CPU: 96.5%
[12:30:46] Процесс "update_helper.exe" нагружает CPU на 45.2%
           → Диалог: "Разрешить убить процесс?"
           
[12:35:12] Высокая нагрузка CPU: 97.1%
[12:35:13] Процесс "update_helper.exe" нагружает CPU на 48.7%
           → Диалог: "Разрешить убить процесс?"
           
[12:40:55] Высокая нагрузка CPU: 98.2%
[12:40:56] Процесс "update_helper.exe" нагружает CPU на 52.3%
           → Диалог: "Разрешить убить процесс?"
           
[12:41:00] Диалог обучения: "Создать правило 'Всегда убивать'?"
           → Если "Да": правило сохранено
```

## 🔒 Безопасность

### Защищенные процессы

Программа **никогда** не завершает системные процессы Windows:

```
system, smss.exe, csrss.exe, wininit.exe, services.exe,
lsass.exe, svchost.exe, explorer.exe, dwm.exe, taskmgr.exe,
runtimebroker.exe, searchindexer.exe, ctfmon.exe, sihost.exe,
shellinfrastructurehost.exe, startmenuexperiencehost.exe
```

### Принцип подтверждения

**Все действия требуют подтверждения пользователя!**

Единственное исключение — процессы, для которых создано правило `kill` или которые изучены системой (после 3+ подтверждений).

## ❓ Часто задаваемые вопросы

### Q: Программа не появляется в трее?
**A:** Убедитесь, что установлены все зависимости (`pip install -r requirements.txt`). Проверьте, не скрыт ли значок в области уведомлений (нажмите на стрелку ^ возле часов).

### Q: Как полностью удалить программу?
**A:** 
1. Выйдите из программы через значок в трее
2. Удалите ярлык из автозагрузки: `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup`
3. Удалите папку с программой
4. Удалите папку данных: `C:\Users\<ВашеИмя>\PCHealthGuardian`

### Q: Можно ли изменить пороги нагрузки?
**A:** Да, отредактируйте файл `pc_health_guardian.py`, найдите строки:
```python
CPU_WARNING_THRESHOLD = 95.0
CPU_CRITICAL_THRESHOLD = 98.0
CHECK_INTERVAL = 2.0
```

### Q: Программа конфликтует с антивирусом?
**A:** Встроенный антивирус использует эвристический анализ по именам процессов. Если возникают ложные срабатывания — отключите его в настройках или добавьте процесс в правила с действием `ignore`.
