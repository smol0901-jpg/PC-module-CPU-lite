# Инструкция по установке и использованию PC Health Guardian

## Для вашего ПК (Intel Celeron N4120, 8GB RAM)

Эта программа специально оптимизирована для вашей конфигурации и будет потреблять минимальное количество ресурсов.

---

## 📋 Шаг 1: Подготовка

### 1.1 Установите Python (если не установлен)
1. Перейдите на https://www.python.org/downloads/
2. Скачайте Python 3.11 или новее для Windows
3. **ВАЖНО**: При установке отметьте галочку ✅ "Add Python to PATH"
4. Нажмите "Install Now"

### 1.2 Проверка установки
Откройте командную строку (Win+R → cmd) и введите:
```
python --version
```
Должно показать: `Python 3.x.x`

---

## 📦 Шаг 2: Установка программы

### Вариант А: Автоматическая установка (рекомендуется)
1. Скопируйте все файлы из папки проекта в удобную папку, например:
   ```
   C:\Programs\PCHealthGuardian\
   ```

2. Дважды кликните на файл `run.bat`
   - Программа автоматически проверит зависимости
   - Установит недостающие компоненты
   - Запустится

### Вариант Б: Ручная установка
1. Откройте командную строку в папке с программой
2. Выполните команды:
```cmd
pip install psutil
python pc_health_guardian.py
```

---

## 🚀 Шаг 3: Добавление в автозагрузку

Чтобы программа запускалась автоматически при включении ПК:

### Способ 1: Через планировщик заданий
1. Нажмите Win+R, введите `taskschd.msc`
2. Справа выберите "Создать задачу"
3. Вкладка "Общие":
   - Имя: `PC Health Guardian`
   - ✅ "Выполнять для всех пользователей"
   - ✅ "Выполнять с наивысшими правами"
4. Вкладка "Триггеры" → "Создать":
   - Начать: "При входе в систему"
5. Вкладка "Действия" → "Создать":
   - Действие: "Запуск программы"
   - Программа: `python.exe`
   - Аргументы: полный путь к `pc_health_guardian.py`
6. Нажмите ОК

### Способ 2: Через реестр (проще)
Программа имеет встроенную функцию автозагрузки. Добавьте в начало файла строку:
```python
add_to_startup()
```

Или создайте файл `install_startup.bat`:
```batch
@echo off
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Run" /v "PCHealthGuardian" /t REG_SZ /d "python \"C:\Programs\PCHealthGuardian\pc_health_guardian.py\"" /f
echo Программа добавлена в автозагрузку!
pause
```

## 💡 Как это работает

### 1. Автоматическое отслеживание
- Программа мониторит ВСЕ процессы, включая обновления Windows
- Если нагрузка CPU > 95%, процесс попадает в список подозрительных
- Системные процессы защищены от завершения

### 2. Обучение
- При первой высокой нагрузке: запись в лог
- При второй: напоминание
- При третьей: предложение создать авто-правило

### 3. Подтверждение действий
Перед завершением процесса вы увидите:
```
============================================================
ТРЕБУЕТСЯ ПОДТВЕРЖДЕНИЕ
Действие: TERMINATE
Процесс: chrome.exe
Причина: Нагрузка CPU: 97%
============================================================
1. Выполнить сейчас
2. Выполнить всегда для этого процесса
3. Отменить
4. Отложить решение

Ваш выбор (1-4):
```

Если выбрать пункт 2 - программа запомнит и будет действовать автоматически.

### 4. Защита от зависания
- Максимальная нагрузка CPU ограничена 98%
- При достижении порога программа ищет самые "тяжелые" процессы
- Предлагает завершить топ-3 процесса по нагрузке

## ⚠️ Важные замечания

### Что НЕЛЬЗЯ делать:
1. Не завершайте системные процессы вручную
2. Не устанавливайте интервал проверки меньше 2 секунд
3. Не отключайте антивирус без необходимости

### Что МОЖНО делать:
1. Создавать правила для конкретных программ
2. Откладывать решения для сложных случаев
3. Просматривать логи для анализа проблем

### Для разработчиков:
Если вы разрабатываете ПО и антивирус мешает:
1. Пункт 5 → Выключить антивирус
2. Или добавьте процесс в исключения в `pc_health_guardian.py`:
```python
SYSTEM_PROCESSES.add('myapp.exe')
```

## 🛠️ Настройка под себя

### Изменение порогов
Откройте `pc_health_guardian.py` и измените константы:

```python
MAX_CPU_THRESHOLD = 98.0  # Максимальная нагрузка (%)
LEARN_THRESHOLD = 95.0    # Порог обучения (%)
CHECK_INTERVAL = 2.0      # Интервал проверки (сек)
```

**Рекомендации для вашего ПК:**
- `MAX_CPU_THRESHOLD`: 95-98%
- `LEARN_THRESHOLD`: 90-95%
- `CHECK_INTERVAL`: 2-5 сек (меньше = больше нагрузка на CPU)

### Добавление процессов в защиту
В начале файла найдите `SYSTEM_PROCESSES` и добавьте:
```python
SYSTEM_PROCESSES.add('important_app.exe')
```

## ❓ Решение проблем

### Программа не запускается
1. Проверьте установку Python: `python --version`
2. Установите зависимости: `pip install psutil`
3. Запустите от имени администратора

### Слишком много запросов подтверждения
Создайте протокол (выберите пункт 2 при подтверждении) - программа будет действовать автоматически.

### Программа потребляет много памяти
1. Увеличьте `CHECK_INTERVAL` до 5 секунд
2. Уменьшите количество сохраняемых логов в коде

### Антивирус блокирует программу
Добавьте папку с программой в исключения вашего антивируса.
