# PC Health Guardian v1.0

Легковесный модуль для защиты ПК от перегрузки, оптимизированный для слабых ПК.

## Требования к системе
- Windows 10/11 (64-bit)
- Python 3.8+
- Минимум 50 MB свободной памяти
- Процессор от Intel Celeron N4120 и выше

## Установка

1. Установите Python (если не установлен):
   - Скачайте с https://www.python.org/downloads/
   - При установке отметьте "Add Python to PATH"

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск

### Обычный запуск:
```bash
python pc_health_guardian.py
```

### Добавить в автозагрузку:
Программа автоматически создаст запись в реестре для запуска при старте системы.

## Возможности

### 1. Мониторинг нагрузки CPU
- Автоматическое отслеживание процессов с высокой нагрузкой (>95%)
- Защита от зависания ПК (максимальная нагрузка не более 98%)
- Приоритетная защита системных процессов

### 2. Система обучения
- Запоминает процессы, которые часто создают высокую нагрузку
- После 3 случаев высокой нагрузки предлагает автоматическое правило
- Применяет изученные правила автоматически

### 3. Антивирус (опционально)
- Простая эвристическая проверка на подозрительные процессы
- Может быть отключена для разработчиков
- Обнаружение по паттернам: miner, trojan, ransom, keylogger

### 4. Система правил
- Добавление пользовательских правил
- Удаление и изменение правил
- Просмотр активных правил

### 5. Подтверждение действий
- Всегда спрашивает подтверждение перед завершением процесса
- Возможность создать протокол для автоматических действий
- Отложенные решения

### 6. Логирование
- Полная история всех действий
- Просмотр последних 1000 событий
- Экспорт логов в JSON

### 7. Работа в трее
- Минимальное потребление ресурсов (<10 MB RAM)
- Работает до перезагрузки ПК
- Невидимый фоновый режим

## Структура данных

Все данные хранятся в `%USERPROFILE%\PCHealthGuardian\`:
- `rules.json` - пользовательские правила
- `logs.json` - история действий
- `learned.json` - изученные процессы
- `config.json` - настройки (антивирус и т.д.)

## Меню управления

1. **Статус системы** - текущая нагрузка CPU/RAM
2. **Логи действий** - история всех событий
3. **Управление правилами** - просмотр правил
4. **Изученные процессы** - статистика по процессам
5. **Настройки антивируса** - вкл/выкл защиту
6. **Добавить правило** - создание нового правила
7. **Удалить правило** - удаление существующего
8. **Выход** - возврат к мониторингу в фоне

## Системные процессы (защищены)

Следующие процессы никогда не будут завершены:
- System, Idle, smss.exe, csrss.exe
- wininit.exe, services.exe, lsass.exe
- svchost.exe, explorer.exe, winlogon.exe
- dwm.exe, taskmgr.exe, registry
- memory compression, interrupts, ntoskrnl.exe

## Настройка порогов

В начале файла `pc_health_guardian.py` можно изменить:
```python
MAX_CPU_THRESHOLD = 98.0  # Максимальная нагрузка CPU %
LEARN_THRESHOLD = 95.0    # Порог обучения %
CHECK_INTERVAL = 2.0      # Интервал проверки (секунды)
```

## Безопасность

⚠️ **Внимание**: Программа может завершать процессы. Всегда внимательно читайте запросы на подтверждение.

## Поддержка

Для слабых ПК рекомендуется:
- Не изменять интервал проверки ниже 2 секунд
- Оставить антивирус включенным
- Регулярно просматривать логи
