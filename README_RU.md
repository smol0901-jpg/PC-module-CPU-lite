# 🛡️ PC Health Guardian v1.0

**Легковесный модуль автономной защиты и оптимизации ПК для слабых систем**

---

## 📖 Описание программы

**PC Health Guardian** — это специализированный программный модуль, разработанный для автономной работы на компьютерах с ограниченными ресурсами (на базе процессоров Intel Celeron N4120, Pentium, Atom и аналогов). 

### 🎯 Основная цель
**Здоровье вашего ПК** — программа предотвращает зависания системы, контролирует критическую нагрузку на процессор и защищает от вредоносного ПО, оставаясь при этом практически незаметной для пользователя и потребляя минимальное количество оперативной памяти (<10 МБ).

Программа работает в фоновом режиме (в системном трее) до перезагрузки компьютера, интеллектуально анализируя процессы и принимая решения на основе пользовательских подтверждений и встроенных правил безопасности.

---

## ✨ Ключевые возможности

### 1. 🧠 Интеллектуальный мониторинг нагрузки
- **Автотрекинг тяжелых процессов:** Постоянный контроль за всеми запущенными задачами, включая фоновые обновления Windows, браузеры и сторонний софт
- **Защита от зависания:** Гарантирует, что общая загрузка CPU не превысит **98%**. При достижении порога программа мягко ограничивает "прожорливые" процессы
- **Системная безопасность:** Автоматически исключает из списка на закрытие критически важные системные процессы (`svchost.exe`, `System`, `csrss.exe` и др.), нарушение работы которых может привести к краху ОС

### 2. 🦠 Встроенный антивирусный модуль
- **Эвристический анализ:** Обнаружение подозрительной активности по именам процессов и поведению (майнеры, трояны, кейлоггеры, ransomware)
- **Режим разработчика:** Возможность полного отключения антивирусного сканирования по желанию пользователя (полезно при тестировании собственного ПО или скриптов)
- **Паттерны угроз:** Обнаружение по ключевым словам: `miner`, `trojan`, `ransom`, `keylogger`, `crypto`

### 3. 🎓 Система самообучения
- **Адаптивность:** Программа запоминает процессы, которые регулярно создают высокую нагрузку (>95%)
- **Авто-правила:** После 3-х случаев высокой нагрузки от одного и того же процесса, модуль предложит создать постоянное правило для него
- **Протоколирование:** Если вы однажды подтвердили действие (например, "завершить процесс X"), система запомнит это и в следующий раз выполнит действие автоматически согласно утвержденному протоколу

### 4. ⚙️ Гибкая система правил и отчетов
- **Управление правилами:** Пользователь может вручную добавлять, удалять или редактировать правила для конкретных приложений
- **История действий:** Полный лог всех событий (кто был загружен, что было завершено, какие вирусы найдены) с возможностью просмотра последних 1000 записей
- **Прозрачность:** Перед любым критическим действием (завершение процесса) программа запрашивает подтверждение, если для этого действия нет ранее сохраненного протокола
- **Экспорт логов:** Возможность экспорта истории в формат JSON для анализа

### 5. 💻 Минималистичный интерфейс
- **Работа в трее:** Программа скрыта в системном трее, не занимая места на рабочем столе
- **Контекстное меню:** Быстрый доступ к статусу, логам и настройкам через правый клик
- **Легковесность:** Потребление менее 10 МБ оперативной памяти

## 🖥️ Системные требования

Программа создана специально для конфигураций уровня:
- **Процессор:** Intel Celeron N4120 (и аналоги) @ 1.10GHz
- **ОЗУ:** от 4 ГБ (комфортно работает при 8 ГБ)
- **ОС:** Windows 10/11 (64-bit)
- **Место на диске:** < 50 МБ
- **Python:** 3.8+

## 📂 Структура хранения данных

Все данные (правила, логи, настройки обучения) хранятся в папке пользователя, чтобы не засорять системный реестр:
```
C:\Users\<Имя_Пользователя>\PCHealthGuardian\
```

| Файл | Описание |
|------|----------|
| `rules.json` | База пользовательских правил (черный/белый список) |
| `logs.json` | История действий и отчетов (до 1000 записей) |
| `learned.json` | База знаний о поведении процессов (обучение) |
| `config.json` | Конфигурация (настройки антивируса, пороги) |

## 🍽️ Меню управления

Программа предоставляет удобное консольное меню при необходимости:

1. **Статус системы** — текущая нагрузка CPU/RAM в реальном времени
2. **Логи действий** — история всех событий с фильтрацией
3. **Управление правилами** — просмотр и редактирование активных правил
4. **Изученные процессы** — статистика по процессам с высокой нагрузкой
5. **Настройки антивируса** — включение/отключение защиты (режим разработчика)
6. **Добавить правило** — создание нового правила вручную
7. **Удалить правило** — удаление существующего правила
8. **Выход** — возврат к мониторингу в фоновом режиме

---

## 🛡️ Защищенные системные процессы

Следующие процессы **никогда** не будут завершены программой (гарантия стабильности ОС):

- `System`, `Idle`, `smss.exe`, `csrss.exe`
- `wininit.exe`, `services.exe`, `lsass.exe`
- `svchost.exe`, `explorer.exe`, `winlogon.exe`
- `dwm.exe`, `taskmgr.exe`, `registry`
- `memory compression`, `interrupts`, `ntoskrnl.exe`

## ⚙️ Настройка порогов

В начале файла `pc_health_guardian.py` можно изменить параметры под ваши нужды:

```python
MAX_CPU_THRESHOLD = 98.0  # Максимальная нагрузка CPU (%)
LEARN_THRESHOLD = 95.0    # Порог обучения (%)
CHECK_INTERVAL = 2.0      # Интервал проверки (секунды)
```

> **Рекомендация для слабых ПК:** Не изменять интервал проверки ниже 2 секунд для минимизации нагрузки на процессор.

## 🔒 Безопасность

⚠️ **Внимание:** Программа может завершать процессы. Всегда внимательно читайте запросы на подтверждение перед первым автоматическим действием.

- По умолчанию все действия требуют подтверждения пользователя
- Автоматическое выполнение возможно только после явного создания протокола
- Системные процессы защищены от завершения

---

## ⚠️ Важное примечание

- **Подтверждение действий:** По умолчанию программа работает в безопасном режиме и спрашивает разрешение на завершение процессов. Автоматическое срабатывание происходит только после того, как пользователь явно подтвердил это действие ранее.
- **Не является заменой полноценному антивирусу:** Встроенный модуль направлен на защиту от "тяжелых" угроз и майнеров, отвлекающих ресурсы ПК. Для комплексной защиты рекомендуется использовать его в связке с основным антивирусом или в режиме разработчика, если вы используете сторонние решения.
