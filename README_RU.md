# 🛡️ PC Health Guardian v2.0 NEURAL_OPTIMIZED

**Легковесный модуль для защиты ПК от перегрузки и зависаний**  
*Оптимизировано для слабых ПК (Intel Celeron N4120, 8GB RAM)*

---

## 📋 Описание

PC Health Guardian — это автономная программа, которая работает в системном трее и защищает ваш компьютер от перегрузок, автоматически управляя тяжелыми процессами. Главная задача модуля — **здоровье вашего ПК**.

### ✨ Ключевые возможности

| Функция | Описание |
|---------|----------|
| 🎯 **Автотрекинг тяжелых процессов** | Мониторинг всех процессов каждые 2 секунды, включая обновления Windows |
| 🦠 **Антивирус** | Эвристическое обнаружение угроз (miner, trojan, keylogger), можно отключить для разработчиков |
| 🧠 **Система обучения** | Запоминает процессы после 3 случаев высокой нагрузки (>95%), предлагает авто-правила |
| 🛡️ **Защита от зависания** | Максимальная нагрузка CPU не более 98% |
| 📜 **Система правил** | Добавление, удаление, изменение правил через GUI |
| 📊 **Журнал действий** | Просмотр истории (до 1000 записей) во вкладке |
| ✅ **Подтверждение действий** | Всегда спрашивает, создает протоколы для повторных действий |

## 🚀 Быстрый старт

### Способ 1: Автоматическая установка (рекомендуется)

1. Скопируйте все файлы в папку (например `C:\Programs\PCHealthGuardian`)
2. Запустите `install.bat` **от имени администратора**
3. Программа добавится в автозагрузку и появится в трее после перезагрузки

### Способ 2: Ручной запуск

```cmd
# Установка зависимостей
pip install -r requirements.txt

# Запуск программы (с консолью)
python pc_health_guardian.py

# Запуск без консоли (только трей)
pythonw.exe pc_health_guardian.py
```

## 🎛️ Кабинет управления (GUI)

### Главное окно
- **Прогресс-бар CPU** — визуализация текущей нагрузки
- **Статус активности** — индикатор работы модуля
- **Кнопки управления**:
  - ⏸ Пауза — временная остановка мониторинга
  - 🦠 Антивирус — включение/выключение защиты
  - 📜 Правила — управление правилами
  - 💾 Экспорт логов — сохранение истории

### Вкладки
- **Журнал** — последние 20 действий в реальном времени
- **Правила** — список активных правил с возможностью удаления

### Системный трей
При закрытии окна программа сворачивается в трей, продолжая работу.

## 🔒 Система безопасности

### Защищенные процессы
Программа никогда не завершает системные процессы Windows:
- `system`, `smss.exe`, `csrss.exe`, `wininit.exe`
- `services.exe`, `lsass.exe`, `svchost.exe`
- `explorer.exe`, `dwm.exe`, `taskmgr.exe`

### Эвристический антивирус
Обнаруживает угрозы по двум критериям:
1. **Подозрительное имя** (miner, trojan, keylog, rat, cryptolocker)
2. **Подозрительный путь** (запуск из Temp, Downloads)

## 🧠 Система обучения

Модуль запоминает паттерны поведения процессов:
- При достижении нагрузки >95% запись инцидента
- После **3 повторений** — предложение создать правило
- Правило применяется автоматически в будущем

## ⚙️ Настройка параметров

Измените константы в начале файла `pc_health_guardian.py`:

```python

LEARNING_THRESHOLD_COUNT = 3   # Повторений для обучения
```
